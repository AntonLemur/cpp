# FTXUI Interactive Graph

Интерактивное консольное приложение на C++ для отрисовки анимированной синусоиды ($y = \sin(x - t)$) в терминале с использованием библиотеки [FTXUI](https://github.com).

## Возможности

* **Плавная анимация в реальном времени** — отрисовка на холсте `ftxui::Canvas` с помощью символов Брайля (~30 FPS).
* **Интерактивное управление** — изменение амплитуды и частоты волны, а также постановка анимации на паузу прямо во время работы.
* **Потокобезопасность** — разделение UI-потока и фонового потока расчёта фазы с использованием `std::atomic` и CAS-циклов (`compare_exchange_weak`).

## Управление

| Клавиша | Действие |
| :--- | :--- |
| `↑` / `↓` | Увеличить / уменьшить амплитуду волны |
| `→` / `←` | Увеличить / уменьшить частоту волны |
| `Пробел` | Поставить анимацию на паузу / продолжить |
| `q` или `Esc` | Выход из программы |

## Требования

* Компилятор с поддержкой **C++17** или новее (GCC, Clang, MSVC)
* **CMake** (версия 3.14 или выше)
* Доступ в интернет при первой конфигурации (для автоматической загрузки FTXUI через `FetchContent`)

## Сборка и запуск

```bash
# 1. Клонирование репозитория
git clone <URL_вашего_репозитория>
cd graph

# 2. Конфигурация и сборка
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build

# 3. Запуск
./build/graph
```

### Отладка многопоточности (опционально)

В проект добавлена поддержка **ThreadSanitizer** (для GCC и Clang на Linux/macOS) для поиска гонок данных:

```bash
cmake -B build-tsan -DENABLE_TSAN=ON
cmake --build build-tsan
TSAN_OPTIONS="log_path=tsan_report.log" ./build-tsan/graph
```
