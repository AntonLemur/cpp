# Firebird TUI Data Browser (FTXUI)

Кроссплатформенное консольное TUI-приложение на современном C++ (C++17) для просмотра и редактирования данных из базы **Firebird** (на примере справочника сотрудников) с поддержкой превью фотографий в терминале и полноэкранного просмотра через SDL2.

## Возможности

* **Интерактивный грид** — прокручиваемая таблица записей с выделением активной строки и поддержкой UTF-8.
* **Просмотр и редактирование карточки** — модальное окно по нажатию `Enter` с редактированием ФИО (`LAST_NAME`, `FIRST_NAME`, `MIDDLE_NAME`) и транзакционным сохранением (`UPDATE`) в Firebird.
* **Превью фото в терминале** — рендеринг портрета из BLOB-поля БД с помощью символов Брайля, кадрированием, автоконтрастом и дизерингом Флойда — Стейнберга (с автоматической адаптацией палитры под графические терминалы и чистую консоль Linux TTY).
* **Полноэкранный просмотр фото (SDL2)** — декодирование и вывод исходного изображения в высоком разрешении прямо из оперативной памяти (`SDL_RWFromConstMem`) с перекрытием окна терминала (X11 / Windows) или через framebuffer в чистой консоли TTY.
* **Кроссплатформенность и RAII** — поддержка сборки под Linux (GCC/Clang) и Windows (MinGW/MSVC), безопасное управление ресурсами Firebird OO API через RAII-обёртки (`FbPtr`, `FbTransactionGuard`).

## Структура проекта

* `main.cpp` — инициализация UI-цикла FTXUI, таблица, модальное окно карточки и маршрутизация событий.
* `db_manager.h` / `db_manager.cpp` — управление подключением к серверу Firebird.
* `db_utils.h` — RAII-обёртки для автоматического освобождения дескрипторов и отката транзакций Firebird.
* `employee_service.h` / `employee_service.cpp` — SQL-выборки списка сотрудников, чтение BLOB-фотографий и обновление данных (`UPDATE`).
* `photo_renderer.h` / `photo_renderer.cpp` — декодирование изображений (`stb_image`) и генерация превью для терминала.
* `photo_viewer.h` / `photo_viewer.cpp` — кроссплатформенный полноэкранный просмотрщик изображений на базе SDL2 и SDL2_image.
* `stb_image.h` — однофайловая библиотека декодирования изображений (Public Domain / MIT).

## Управление

| Клавиша | Контекст | Действие |
| :--- | :--- | :--- |
| `↑` / `↓` | Таблица | Навигация по списку записей |
| `Enter` | Таблица | Открыть карточку выбранной записи |
| `q` или `Esc` | Таблица | Выход из программы |
| `↑` / `↓` или `Tab` | Карточка | Переход между полями ввода и кнопками |
| `←` / `→` | Карточка | Перемещение курсора в тексте / переключение кнопок |
| `F2` | Карточка | Открыть фото в полном разрешении (SDL2) |
| `Enter` (на кнопке) | Карточка | Сохранить изменения в БД или отменить |
| `Esc` | Карточка | Закрыть карточку без сохранения |

## Требования

* Компилятор с поддержкой **C++17** или новее (GCC, Clang, MinGW, MSVC)
* **CMake** версии 3.16 или выше
* Клиентская библиотека Firebird (**`fbclient`** / Firebird OO API)
* Библиотеки разработки **X11** (для Linux, используется для определения геометрии окна терминала)
* Зависимости **FTXUI**, **SDL2** и **SDL2_image** загружаются автоматически через `CMake FetchContent`

## Сборка и запуск

```bash
# 1. Конфигурация проекта
cmake -B build -DCMAKE_BUILD_TYPE=Release

# 2. Сборка
cmake --build build

# 3. Запуск
./build/datafromdb
```
