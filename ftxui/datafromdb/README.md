# Firebird TUI Data Browser (FTXUI)

Кроссплатформенное консольное TUI-приложение на современном C++ (C++17) для просмотра и редактирования данных из базы **Firebird** (на примере справочника сотрудников) с живым поиском, встроенным файловым менеджером с предпросмотром изображений и полноэкранным просмотром через SDL2.

## Возможности

* **Интерактивный грид и живой поиск** — прокручиваемая таблица записей с выделением активной строки и мгновенной регистронезависимой фильтрацией (включая кириллицу UTF-8) по ФИО и табельному номеру.
* **Просмотр и редактирование карточки** — модальное окно по нажатию `Enter` с редактированием ФИО (`LAST_NAME`, `FIRST_NAME`, `MIDDLE_NAME`), заменой фотографии и транзакционным сохранением (`UPDATE`) в Firebird.
* **Встроенный TUI-проводник с предпросмотром** — навигация по каталогам с помощью `std::filesystem` и живой генерацией превью выбранного файла (`.jpg`, `.jpeg`, `.png`, `.bmp`) прямо в окне терминала.
* **Загрузка BLOB в БД** — сегментированная потоковая запись изображений в BLOB-поля Firebird.
* **Превью фото в терминале** — рендеринг портрета из BLOB-поля БД с помощью символов Брайля, кадрированием, автоконтрастом и дизерингом Флойда — Стейнберга (с автоматической адаптацией палитры под графические терминалы и чистую консоль Linux TTY).
* **Полноэкранный просмотр фото (SDL2)** — декодирование и вывод исходного изображения в высоком разрешении прямо из оперативной памяти (`SDL_RWFromConstMem`) с перекрытием окна терминала (X11 / Windows) или через framebuffer в чистой консоли TTY.
* **Кроссплатформенность и RAII** — поддержка сборки под Linux (GCC/Clang) и Windows (MinGW/MSVC), безопасное управление ресурсами Firebird OO API через RAII-обёртки (`FbPtr`, `FbTransactionGuard`).

## Структура проекта

* `main.cpp` — инициализация UI-цикла FTXUI, таблица с живым поиском, модальное окно карточки и маршрутизация событий.
* `db_manager.h` / `db_manager.cpp` — управление подключением к серверу Firebird.
* `db_utils.h` — RAII-обёртки для автоматического освобождения дескрипторов и отката транзакций Firebird.
* `employee_service.h` / `employee_service.cpp` — SQL-выборки списка сотрудников, чтение и потоковая запись BLOB-фотографий, обновление данных (`UPDATE`).
* `file_picker.h` / `file_picker.cpp` — кроссплатформенный TUI-проводник файлов с живым предпросмотром изображений.
* `photo_renderer.h` / `photo_renderer.cpp` — декодирование изображений (`stb_image`) и генерация превью для терминала.
* `photo_viewer.h` / `photo_viewer.cpp` — кроссплатформенный полноэкранный просмотрщик изображений на базе SDL2 и SDL2_image.
* `stb_image.h` — однофайловая библиотека декодирования изображений (Public Domain / MIT).

## Управление

| Клавиша | Контекст | Действие |
| :--- | :--- | :--- |
| `/` или `F3` | Таблица | Перейти в строку живого поиска |
| `↑` / `↓` | Таблица | Навигация по списку записей |
| `Enter` | Таблица | Открыть карточку выбранной записи |
| `q` или `Esc` | Таблица | Выход из программы |
| `Enter` или `↓` | Строка поиска | Перейти к найденным записям в таблице |
| `Esc` | Строка поиска | Очистить поиск или вернуться в таблицу |
| `↑` / `↓` или `Tab` | Карточка | Переход между полями ввода и кнопками |
| `F2` | Карточка | Открыть фото в полном разрешении (SDL2) |
| `Enter` (на кнопке) | Карточка | Изменить фото / Сохранить изменения в БД / Отменить |
| `Esc` | Карточка | Закрыть карточку без сохранения |
| `↑` / `↓` | Проводник файлов | Навигация по папкам и изображениям (с превью справа) |
| `Enter` | Проводник файлов | Войти в каталог или выбрать изображение |
| `Backspace` | Проводник файлов | Перейти в родительский каталог (`..`) |
| `Esc` | Проводник файлов | Закрыть проводник без выбора файла |

## Требования

* Компилятор с поддержкой **C++17** или новее (GCC, Clang, MinGW, MSVC)
* **CMake** версии 3.16 или выше
* Клиентская библиотека Firebird (**`fbclient`** / Firebird OO API)
* Библиотеки разработки **X11** (для Linux, используется для определения геометрии окна терминала)
* Зависимости **FTXUI**, **SDL2** и **SDL2_image** загружаются автоматически через `CMake FetchContent`

## Сборка и запуск

```bash
# 1. Конфигурация проекта
cmake -B build -DCMAKE_BUILD_TYPE=Release

# 2. Сборка
cmake --build build

# 3. Запуск
./build/datafromdb
```
