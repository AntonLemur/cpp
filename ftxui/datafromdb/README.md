# Firebird TUI Client (FTXUI)

Консольное TUI-приложение на современном C++ для просмотра данных из базы Firebird (на примере справочника сотрудников) с поддержкой превью фотографий в терминале и полноэкранного просмотра через SDL2.

## Возможности

* **Интерактивный грид** — прокручиваемая таблица сотрудников с выделением активной строки и поддержкой UTF-8.
* **Карточка сотрудника** — модальное окно с подробными данными по нажатию `Enter`.
* **Превью фото в терминале** — рендеринг портрета из BLOB-поля БД с помощью символов Брайля, кадрированием, автоконтрастом и дизерингом Флойда — Стейнберга (с автоматической адаптацией палитры для графических терминалов и чистой консоли Linux TTY).
* **Встроенный просмотр фото из памяти** — открытие исходного изображения в высоком разрешении без сохранения временных файлов на диск с помощью **SDL2** и **SDL2_image** (работает как в оконном режиме X11/Wayland/Windows, так и напрямую в консоли Linux TTY через KMS/DRM).
* **Модульная архитектура** — разделение слоёв доступа к БД (`DBManager`, `employee_service`) и представления (`photo_renderer`, `photo_viewer`).

## Структура проекта

* `main.cpp` — инициализация UI-цикла FTXUI, таблица и модальное окно карточки.
* `employee.h` — модель данных сотрудника (`Employee`).
* `db_manager.h` / `db_manager.cpp` — управление подключением к серверу Firebird.
* `employee_service.h` / `employee_service.cpp` — SQL-выборки списка сотрудников и полных данных с вычитыванием BLOB-фотографии.
* `photo_renderer.h` / `photo_renderer.cpp` — декодирование изображений (`stb_image`) и генерация превью для терминала.
* `photo_viewer.h` / `photo_viewer.cpp` — просмотр фотографий в высоком разрешении через SDL2 / SDL2_image.
* `stb_image.h` — однофайловая библиотека декодирования изображений.
* `CMakeLists.txt` — сценарий сборки с автоматическим подключением зависимостей (`FTXUI`, `SDL2`, `SDL2_image`) через `FetchContent`.

## Управление

| Клавиша | Контекст | Действие |
| :--- | :--- | :--- |
| `↑` / `↓` | Таблица | Навигация по списку сотрудников |
| `Enter` | Таблица | Открыть карточку выбранного сотрудника |
| `q` или `Esc` | Таблица | Выход из программы |
| `f` | Карточка | Открыть фото сотрудника в высоком разрешении |
| `Esc`, `q` или `Enter` | Просмотр фото | Закрыть окно просмотра и вернуться в карточку |
| `Esc` или `Enter` | Карточка | Закрыть карточку и вернуться в таблицу |

## Требования

* Компилятор с поддержкой **C++17** или новее (GCC, Clang, MSVC)
* **CMake** версии 3.14 или выше
* Клиентская библиотека Firebird (**`fbclient`** / Firebird OO API)
* **Зависимости для сборки SDL2 в Linux (Ubuntu/Debian):**
  * Для поддержки прямого вывода графики в чистом TTY (KMS/DRM):
    ```bash
    sudo apt update && sudo apt install libdrm-dev libgbm-dev libudev-dev
    ```
  * *(Опционально)* Для поддержки звука ALSA и графических серверов X11/Wayland, если не установлены:
    ```bash
    sudo apt install libasound2-dev libx11-dev libxext-dev libwayland-dev libxkbcommon-dev
    ```

## Настройка и сборка

1. **Настройка подключения к БД:**
   Перед сборкой укажите актуальные параметры подключения (путь к базе, логин, пароль) в `db_manager.cpp` (или в конфигурационном файле, если он вынесен отдельно).

2. **Конфигурация и сборка проекта:**
   *(При первой конфигурации CMake автоматически загрузит `FTXUI`, `SDL2` и `SDL2_image`)*
   ```bash
   cmake -B build -DCMAKE_BUILD_TYPE=Release
   cmake --build build
   ```

3. **Запуск:**
   ```bash
   ./build/datafromdb
   ```
   *(Для работы просмотра фото в чистом Linux TTY без `sudo` убедитесь, что ваш пользователь состоит в группах `video`, `render` и `input`: `sudo usermod -aG video,render,input $USER`)*.
